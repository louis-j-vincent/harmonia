Les vraies matrices. Les 48 colonnes de X et de V sont 4 mesures × 12 hauteurs — les traits verticaux séparent les mesures. Clique une ligne pour l'écouter.

grille
X — ce qu'on donne
une ligne = un bloc de 4 mesures du morceau, mis bout à bout
U — où sont les sections
une ligne = le même bloc ; une colonne = une section. Clair = « ce bloc EST cette section ». Idéalement une seule case allumée par ligne.
V — les sections elles-mêmes
une ligne = une section, écrite une fois : ses 4 mesures d'accords
U·V — ce qu'on récupère
à comparer avec X, à l'œil, sur la même échelle de couleur. Ce qui manque ici est le « ≈ ».
