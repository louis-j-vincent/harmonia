Replier les tours qui se ressemblent

On découpe le morceau en tours de 4 mesures, on les groupe par ressemblance harmonique sans regarder les lettres, et on ne parle de variation que dans les groupes assez fournis pour arbitrer.

  1. les tours sont ancrés sur les sections, pas pavés depuis la mesure 1 ;
  2. on groupe au-dessus de 0.80 de distance harmonique — seuil pris sur tes deux arbitrages : A- contre C à 0,83 se replie, C-7 contre G7 à 0,74 non ;
  3. 3 tours minimum pour replier. En dessous, deux lectures ne disent pas laquelle est la variante de l'autre : ce sont des mesures différentes ;
  4. une variante doit revenir 2 fois pour être écrite — vue une seule fois sur huit tours, c'est du décodage, pas un choix.
